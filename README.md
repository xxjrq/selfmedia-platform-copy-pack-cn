# 多平台发布文案包

![多平台发布文案包推广图](assets/promo-1600x900.png)

将一份已定稿内容快速整理成可复制的多平台标题、简介和相关标签草稿。输入定稿内容、真实来源与平台名单，得到逐平台的表达适配；资料不齐时会明确列出缺项，不编造事实、不上传内容，也不承诺标签热门或平台流量。

## 安装

```bash
npx skills add xxjrq/selfmedia-platform-copy-pack-cn
```

## 输入与结果

必需输入：已定稿内容、真实来源、目标平台名单。可选补充受众、语气、禁用词和字数限制。适用单次章节、场景或短文；表格最多100行，超出请分批提供。

结果按平台输出标题候选、简介/导语、相关标签草稿和适配说明，并保留需要发布前核对的事项。查看可复制的[成功交付](fixtures/success.md)与[缺料交付](fixtures/failure.md)。

## 使用边界

本 Skill 只处理内容表达适配，不登录账号、不自动发布、不上传材料。标签仅为相关性草稿，最终事实核验与发布由用户完成。

## 自检

```bash
node scripts/self-test.mjs
```
